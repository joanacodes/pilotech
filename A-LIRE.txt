Mise à jour n°3 — cartes « 3 solutions », diaporama, préchargeur, FormSubmit
============================================================================

1. Dézipper ce dossier À LA RACINE de C:\Projets\pilotech (les fichiers remplacent les anciens).
   Si Windows crée un sous-dossier « pilotech-maj-3 », déplacer son contenu à la racine.

2. PowerShell, à la racine du projet :
   git add .
   git commit -m "Cartes 3 solutions, diaporama accueil, préchargeur, envoi FormSubmit"
   git push

3. Attendre une minute, puis Ctrl+F5 sur https://joanacodes.github.io/pilotech/

4. FormSubmit : faire UN envoi de test depuis le site en ligne. L'adresse info.pilotech@gmail.com reçoit
   un e-mail « Activate form » : cliquer le lien une fois. Ensuite tout arrive dans cette boîte.
