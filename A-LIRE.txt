Mise à jour n°2 — mode sombre, logo, préchargeur, favicon
=========================================================

1. Dézipper ce dossier À LA RACINE de C:\Projets\pilotech en acceptant le remplacement des fichiers.
   (_config.yml n'est pas inclus : votre baseurl "/pilotech" est conservé.)

2. Dans PowerShell, à la racine du projet :
   git rm -r --quiet assets/img/blog                 # visuels du blog, plus utilisés
   git rm --quiet assets/img/brand/favicon.svg       # remplacé par favicon.ico / png
   git add .
   git commit -m "Mode sombre, nouveau logo, préchargeur, favicon"
   git push

3. Attendre une minute, puis Ctrl+F5 sur https://joanacodes.github.io/pilotech/
